# Запрос учебного контента для платформы «ЦифроРус-Курс»

**Кому:** автору курса / научному руководителю
**От:** разработчика платформы
**Дата:** 19.07.2026

## Зачем этот документ

Платформа «ЦифроРус-Курс» технически готова: работают личный кабинет студента,
сдача заданий, ИИ-дневник, форум, рецензирование, панель преподавателя,
итоговая ведомость (120 баллов) и экспорт в Excel.

Чтобы наполнить курс реальным содержанием, нужен учебный материал из УМК.
Ниже — что именно требуется и в каком формате. Можно заполнить прямо в этом
файле или прислать отдельным документом (Word/Google Docs) — главное, чтобы
структура совпадала.

## 1. ОБЯЗАТЕЛЬНО — Тест Модуля 1 (30 вопросов)

Это единственное, что блокирует запуск теста с **автоматической проверкой**.

**Что нужно:** 30 вопросов, 3 блока по 10:
- Блок A — LMS (вопросы 1–10)
- Блок B — ИИ в образовании (вопросы 11–20)
- Блок C — Цифровая этика (вопросы 21–30)

**Для каждого вопроса:**
1. Формулировка вопроса
2. Варианты ответа (обычно 4)
3. **Правильный ответ** (буква или номер)

### Пример заполнения

```
Вопрос 1
Блок: LMS
Текст: Как называется система управления обучением?
Варианты:
  А) Система управления обучением (LMS)
  Б) Текстовый редактор
  В) Мессенджер
  Г) Электронная таблица
Правильный ответ: А
```

### Шаблон (скопируйте и заполните 30 раз)

```
Вопрос N
Блок: LMS / ИИ / Этика
Текст:
Варианты:
  А)
  Б)
  В)
  Г)
Правильный ответ:
```

> Если вопросы уже готовы в файле УМК с ключами — достаточно прислать этот файл,
> перепечатывать не нужно.

## 2. ЖЕЛАТЕЛЬНО — Официальные рубрики итоговых заданий

Сейчас для ИИ-оценивания итоговых заданий используются **черновые** рубрики,
составленные разработчиком. Если в УМК есть утверждённые критерии — пришлите их,
и мы заменим черновики на официальные.

Итоговые задания, оцениваемые ИИ + экспертом:
- Модуль 1 — Эссе (Часть Б), 20 баллов
- Модуль 2 — Итоговый проект (фрагмент курса), 25 баллов
- Модуль 3 — Рефлексивное эссе, 25 баллов
- Модуль 4 — Итоговый кейс, 20 баллов

**Для каждого задания нужно:** 4 критерия, у каждого — описание 4 уровней (0–3 балла).

### Пример

```
Задание: Эссе Модуля 1
Критерий 1: Раскрытие темы
  0 — тема не раскрыта
  1 — затронута поверхностно
  2 — раскрыта с опорой на понятия курса
  3 — раскрыта полно, с опорой на LMS и цифровую этику
Критерий 2: …
Критерий 3: …
Критерий 4: …
```

## 3. ЖЕЛАТЕЛЬНО — Полные формулировки заданий 1.1–4.4

Сейчас в кабинете у каждого задания есть только название. Чтобы студент видел
**полную инструкцию**, пришлите текст-условие каждого задания (что сделать,
объём, форма сдачи).

Список заданий, для которых нужны формулировки:

| Модуль | Задания |
|---|---|
| 1 | 1.1 Сравнительная таблица LMS · 1.2 Пример «галлюцинации» ИИ · 1.3 Форумный пост · 1.4 Конспект документов |
| 2 | 2.1 Структура курса · 2.2 Три учебных задания · 2.3 Рубрика оценивания · 2.4 Интеграция мультимедиа |
| 3 | 3.1 Структурирование с ИИ · 3.2 Стилистическая правка · 3.3 Перефразирование · 3.4 Верификация галлюцинаций |
| 4 | 4.1 План учебной недели · 4.2 Аналитический отчёт · 4.3 Моделирование ситуаций · 4.4 Рецензия на работу |

### Пример

```
Задание 1.1 — Сравнительная таблица LMS
Инструкция: Составьте таблицу сравнения двух LMS (Moodle и Google Classroom)
по 5 критериям и напишите вывод (150–200 слов).
Форма сдачи: текст + при необходимости ссылка на файл.
```

## 4. Что уже реализовано (для справки)

- Регистрация студента (вуз из 4, группа, ФИО, пароль), личный кабинет
- 4 модуля с заданиями, статусы и прогресс, итог 120 баллов и уровень
- Сдача заданий (черновик / отправка), автосохранение каждые 2 минуты
- Портфолио всех работ студента
- ИИ-дневник (Модуль 3): промпт / ответ ИИ / критическая переработка
- Форум (пост + ответы), рецензирование работ сокурсников
- Панель преподавателя: очередь на проверку, ИИ-подсказка по рубрике,
  выставление балла, одобрение рецензий, ИИ-дневники студентов
- Итоговая ведомость + экспорт в Excel

## Приоритет

1. **Раздел 1 (тест)** — без него не запускается автопроверка теста.
2. Разделы 2 и 3 — улучшают качество, но платформа работает и без них
   (используются черновые рубрики и краткие названия заданий).
